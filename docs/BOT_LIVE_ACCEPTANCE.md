## 验收范围与环境

- 使用独立的普通研究员验收账号、组织和合成项目；账号/组织由本机集成测试夹具建立，登录、创建项目、保存模型配置、检查能力、启动任务和保存计划均经过真实界面及 API。
- 合成内容只有三条 UI 检查笔记：Bot 入口可达、记录与参数可查、工作区保留任务上下文。任务没有授权外部检索、科研写入或计算提交。
- 复用本机共享模型配置，通过项目配置接口保存；没有读取其他项目的 API key。验收 provider 使用已有、有效且模型/endpoint 匹配的价格配置，保留后端费用保护。
- 后端为本机已经运行的独立发布版本 `e2389674e7d941b330e5cbd7e146e1f50c208c4c`。本轮修改并验证的是前端分支，没有覆盖部署中的后端或将本次提交冒充已部署版本。
- 后端门户来源校验拒绝临时端口的登录。验收使用同一门户允许的 IPv6 localhost 地址；未关闭来源校验。
- 原始响应和运行截图保留在本机验收目录；公开仓库仅保存这份去除敏感信息的结果。验收结束后停用临时账号、撤销其会话并删除临时凭据副本；合成项目和任务记录保留用于追溯。

## 已修复清单

- [x] **创建后的遮挡**：创建并选中项目后自动关闭管理抽屉，管理抽屉也有明确关闭按钮。
- [x] **模型入口权限不一致**：Bot 侧栏和完整工作区按配置 API 的项目写权限显示模型设置，与全局设置保持一致；项目只读、全局 viewer 和演示模式继续禁用写操作。
- [x] **检查失败没有下一步**：显示资格检查原因，并提供“配置或诊断模型”；后端只返回 `DomainError` 时引导通过连接测试查明凭据、价格或额度问题，不虚构具体原因。
- [x] **模型切换后的旧状态**：保存后刷新当前项目任务资格，清除旧模型的连接成功结果。
- [x] **消息与轮数混淆**：工具返回消息与配置轮数上限分开显示，列表和详情文案统一；明确平台额外限制，未计量成本不显示为免费。
- [x] **保存了却找不到记录**：保存计划后直接进入时间线并展开、聚焦对应记录，避免没有关联目标的计划在树视图中不可见。
- [x] **保存后时间线仍旧**：修正失效的缓存键，从 `timeline` 改为实际读取的 `project-timeline`。
- [x] **记录定位与项目串联**：时间线子视图和记录 ID 进入 URL；切换项目清除定位参数；不存在的记录提供说明并保留已有历史。
- [x] **320px 英文标签拥挤**：三个主标签等分、允许换行，每个点击区域至少 44px 高；浏览器测试增加尺寸和内容溢出断言。
- [x] **工作树开发字体 403**：Vite 允许已解析的共享依赖目录提供资源，不扩大到另一个源码工作树；配置仍可被现有审计测试导入。
- [x] **工作流键盘审计时序**：完整矩阵中发现图节点测量结束前就采集 Tab 顺序；改为等待 React Flow 节点可见后采集，保留所有焦点和样式断言。

复现真实流程需要已登录的测试账号和可用模型配置：创建合成项目，在 Bot 中选择“定义研究目标”，关闭方法包和写入授权，检查模型能力，再提交限定读取项目摘要的任务。任务结束后，从“决策与参数”检查过程和参数，保存待审核计划，展开工作区，再打开已保存记录并返回。复核 Worker 记录与费用台账，不能用静态 fixture 替代。

仍有服务端边界：当前任务资格接口可能只返回异常类别；前端因此提供诊断路径。运行响应没有独立的历史模型配置快照，也没有本次 CNY 台账字段，不能拿当前模型设置或零值冒充历史模型与实际账单。
