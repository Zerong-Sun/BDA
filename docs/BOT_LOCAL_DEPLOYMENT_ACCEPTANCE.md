## 发现与修复

- [x] **展开交付时来源标识符被裁切**：真实新任务包含较长工具调用 ID；320px 下完整交付章节的宽度为 261px，内容达到 272px，被折叠面板裁切。交付区现在允许长文本按可用宽度断行，完整章节、缺失项和来源列表均继承这一规则。
- [x] **浏览器覆盖不足**：原回归只检查折叠状态和保存后的时间线。新增长来源标识符样本，展开“完整交付”和“来源与操作记录”，逐项检查正文与来源列表宽度。该断言在修复前失败，修复后通过。
