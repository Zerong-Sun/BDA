## 结论与实际配置

使用用户提供的 `https://api.deepseek.com/v1` 和 `deepseek-flash`，真实连接成功，首次简短测试耗时 1.47 秒。该模型名称也见 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)。本地合成预览项目采用 `thinking.type=disabled`、`temperature=0.1`、`max_tokens=4096`，其他项目的模型设置保持原样。旧配置已保留恢复材料。

四项协议检查均通过：结构化 JSON、固定来源及数值保留、可用路线选择、函数调用参数。这是协议样例验收，不代表它能独立判断科研结论。

本轮最重要的改动是让**专用实验计算回答直接使用计算器结果**。模型选择工具和组织参数，服务端负责计算、单位、公式、适用条件与来源的最终呈现。模型可继续完成后续计算，结束时只报告完成状态和待补参数，不再改写计算说明。普通科研讨论和多步骤研究任务仍保留模型综合回答。

## 测试发现及处理

| 发现 | 处理与边界 |
| --- | --- |
| 简单问候、缺信息问题容易扩成规则说明，结论和局限反复出现 | 增加独立表达约定：结论先行、条件集中说明、缺参数先问、保留用户要求的详细报告。模型仍偶有冗长，不能把提示词当作强制保证 |
| 有时把孵育后残余活性高外推为一般稳定性更好 | 明确区分观察与假设，要求论点、原文、链接、有限推断和缺口分开。样例中仍出现不合适的后续建议，需继续保留人工复核 |
| 合成文献被当作实际来源处理，甚至建议读取虚构论文全文 | 要求显著标注合成样例。当前仍不是完全可靠的科学解释器，不能据此自动审核或写入已验证证据 |
| 新计算器可在 UI 使用，但 Bot 工具表尚未提供 | 注册 `calculate_bench`，复用同一后端计算服务及输入校验，覆盖 9 类标量计算；序列计算继续在独立工具页完成，不开放读取库中序列 |
| A260 数值正确，却追加“实际光程不是 1 cm 就重算”的错误解释 | 专门选择 `wetlab-read`、工具范围限于实验读取/计算时，收集新计算器结果直接呈现；保留后续工具调用，待模型报告完成或待补参数后统一交付；其他综合研究任务仍保留常规回答 |
| 长计算回答还会被通用科学审阅模型再次改写 | 为服务端计算交付增加明确标记，跳过措辞改写；保留原始工具结果和公式。普通科研内容仍走科学审阅 |
| 上游达到输出上限时，部分正文可能被当成完成结果 | 检查 `finish_reason=length`，返回 `llm_output_truncated`；实际将输出限为 8 tokens 验证了该行为 |
| 开启思考并非稳定改善 | 单次思考模式样例更慢、消耗更多 tokens；出现过被上游标为 `stop` 的不完整短回答。因此本地预览未默认开启思考，长度门控也不能识别所有语义不完整情况 |

## 固定六题对照

固定题目涵盖：平台能力问候、A260 缺参数、A280 结果解释、合成摘要论据整理、无真实结果时的路线优越性判断、检索失败与新颖性的区别。所有论文和结果场景均为合成夹具；没有把真实项目材料上传作批量评测。相同模型、非思考模式、temperature 0.1、每题输出上限 1200 tokens，分别使用旧科学约束及增加表达约定后的版本。

| 指标（6 题合计，延迟为每题平均） | 原约束 | 增加表达约定 |
| --- | ---: | ---: |
| 可见回答字符数 | 5,655 | 3,582 |
| 输出 tokens | 3,199 | 2,061 |
| 输入 tokens | 3,923 | 6,215 |
| 总 tokens | 7,122 | 8,276 |
| 平均请求耗时 | 4.06 秒 | 3.33 秒 |

这批回答字符数减少约 36.7%，输出 tokens 减少约 35.6%；新增约束使**总 tokens 增加约 16.2%**，所以不能称为已证实降本。延迟受网络、缓存和采样影响，六题单次对照不能推广为稳定加速或总体准确率。开发中另外尝试了表达约定的位置及思考模式，未据此宣称最优参数；这里比较的是实际落地的表达约定配置。

## 真实工具与本地服务验收

- 明确 dsDNA、A260=1、已扣空白、1 cm 归一化、未稀释：真实模型选择 `calculate_bench`，服务端返回 **50 ng/µL**。
- 1 µM 原液配成 10 nM，终体积 1000 µL：返回 **10 µL 原液、990 µL 稀释液**。
- 真实两步请求：先由归一化 A260=1 得出 50 ng/µL，再配制 100 µL、10 ng/µL，连续调用计算器返回 **20 µL 原液、80 µL 稀释液**。
- 多步请求不因第一项计算成功而提前结束；最终状态格式无效或仍缺参数时，保留已算出的结果并标注未完成。
- 仅说 A260=1：该次工具循环未擅自执行计算，返回待补充信息；后续仍需防止模型在说明中加入不必要的假设数值。
- 本地 API → 队列 → worker → 模型 → 注册工具 → 已完成消息链路通过；试算没有创建实验记录。
- 计算工具权限、非法数值、重复光程校正、返回公式和来源、专用模式连续计算与结构化完成状态、无效完成状态降级为未完成、输出截断检测均有自动回归。未改数据库 schema。
- 最终代码后端全量回归：**2,573 通过、7 跳过**；Ruff 和 331 个源文件的 MyPy 检查通过。本地两步聊天的最终正文与服务端渲染结果逐字核对一致，API、worker、调度器及存储就绪检查均通过。前端代码本轮未改动。

下一步的质量投资应放在持续评测与可验证的证据交付：增加真实且可公开的段落—论点金标准、反例与缺失数据测试；把关键事实放在结构化字段中并检查来源；独立记录工具数值与模型解释的分歧。复杂科学方案可再比较思考模式或额外评审调用，但必须用质量和实际调用成本一起决定，而非只看回答长度。
