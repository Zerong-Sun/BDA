## 修复清单

以下问题均在本轮复核中处理。

- [x] **P1 — 新导航按钮漏写 `type`，组件审计失败。** 添加 `type="button"`；保持审计规则原样。
- [x] **P1 — 两个整合测试仍绑定旧外壳结构。** 更新顶栏／导航组合与固定视口外壳契约；完整单测重新执行，不删去断言。
- [x] **P2 — 在长工具目录靠下的位置切换，视图仍停留在旧滚动位置。** 目录切换时回到工作区并聚焦新标题；顶部下拉框保留自身的焦点返回，避免与弹层焦点管理冲突。覆盖草稿保留和无效链接恢复。
- [x] **P2 — 手机菜单中的抽屉触发项会卸载，缺少稳定的焦点返回目标。** 打开助手、设置或活动前将焦点移至常驻“更多操作”按钮；浏览器实际验证 Escape 返回。
- [x] **P2 — 手机菜单只验证存在，未验证真实导航。** 菜单项使用路由链接，新增项目保留、嵌套路由及无项目场景测试；浏览器验证返回。
- [x] **P2 — 320px 下新增搜索入口挤压品牌，与帮助按钮重叠。** 窄屏压缩品牌宽度，并以实际边界矩形验证控件无重叠。
- [x] **P2 — 手机工具页说明和重复目录按钮把工作区向下推。** 手机显示简短说明；目录浏览与工具选择共用一行，不额外占一整行。
- [x] **P2 — 原有浏览器覆盖不足以发现断点与高度问题。** 新增 19 个工作台场景，检查导航常驻、页面宽度、工具切换、焦点、历史及零业务写入。
- [x] **P3 — 导览仍提示点击已移除的“工作台”菜单。** 更新中英文文案，并完整走通导览。
- [x] **P3 — 旧导航样式与新规则覆盖堆叠。** 清理旧 `.science-navigation` 样式，直接调整原有背景与目标文字限制，避免继续叠加反向覆盖。

## 可重复执行的验证

从仓库根目录执行：

```sh
npm --prefix frontend test
npm --prefix frontend run lint
npm --prefix frontend run build
npm --prefix frontend run test:browser
npm --prefix frontend run test:workspace-ux
node --experimental-strip-types frontend/scripts/browser-tour.mjs
```

`test:workspace-ux` 输出 `/tmp/bda-workspace-ux/results.json` 和逐场景截图；可用 `BDA_WORKSPACE_UX_OUTPUT` 指定输出目录，或 `BDA_WORKSPACE_UX_CASES` 逗号分隔场景 ID 定向复测。现有浏览器矩阵输出路径由执行结果打印。
