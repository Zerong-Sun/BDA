## 默认使用路径

以下引导面向桌面网页版，兼顾新手与专业用户；手机端不在当前交付范围内。

1. **创建项目**：填写名称、项目类型、目标和约束即可创建。完整任务书可手写，也可让 AI 起草后检查。没有可用模型仍可手动建项目。AI 草案失败会显示原因，不会被当作成功任务书。
2. **目标与问题**：确认任务书、靶标身份、输入结构和成功标准，建立研究问题。项目首页突出当前步骤；完整指标和已就绪的靶标详情可展开查看。
3. **文献与证据**：证据概览、参考文献、结构、数据位于同一分区的二级入口。AI 文献调研打开统一任务计划，检查模型的任务能力后，可分别授权外部文献检索和保存待审核笔记；未授权写入时只读取已有资料。任务限定在调研配方允许的能力内，并可在后台恢复。离开页面后可回到任务列表查看结果。中文主题先转换为英文检索词；转换失败要求修正查询，不把空结果伪装成成功。
4. **实验方案**：比较已有方法，再进入工作流。AI 仅能从服务端模板目录选择，返回理由、已提供的证据 ID 和缺失信息。它不编造脚本、插件和参数。无法验证的推荐不自动选择模板；用户可以比较模板或手动建图。
5. **决策记录**：按目标纵向展开决策卡片，保留支持、否定、未定结论及干湿实验来源。目标分支可折叠，卡片可展开推理与证据。同一个组件服务研究页和实验时间线。
6. **运行与回收**：工作流检查通过后，“开始运行”打开提交预览。查看后端、默认队列和每个计算节点的脚本，再点“确认并提交作业”。后台排队、执行、收集产物；人工步骤不创建计算作业。候选样品进入订购后，项目引导转到实验阶段，测量结果再进入结果比较。

旧 Research 链接仍可用，例如 `tab=literature` 转到参考文献子视图。四个主分区分别是目标与问题、文献与证据、实验方案、决策记录。

## 模型配置与失败处理

任务书、对话、后台 agent、中文检索和 AI 路线推荐遵循同一选择顺序：明确指定的有效模型、项目绑定模型、唯一的平台默认模型。明确选择失效时返回不可用，不悄悄切到其他模型。其他项目的 BYOK 不参与默认选择。

默认模型的配置规则、凭据管理、工具权限和接口清单统一见 [Copilot 服务指南](COPILOT_SERVICE_GUIDE.md)。存在模型选择歧义时，需要管理员明确配置。

生产环境继续使用管理员维护的凭据引用，浏览器不提交密钥；新手无需填写 API Key。开发环境允许项目 BYOK。高级设置可查看模型配置，项目配置不能覆盖共享模型的地址和名称。读取继承配置不会创建数据库记录。

AI 文献笔记和路线建议均需人工核查。读取摘要不能等同于读过正文；模板选择成功不能等同于科研结论成立。现有“生成相似研究”仍是已有研究资料的派生入口，完整文献调研应使用“AI 辅助文献调研”。

## 脚本和提交规则

- 注册插件定义执行命令、容器或原生环境、参数 schema、输入输出端口和资源。AI 提议方案，平台按声明生成脚本。
- 模板缺少必需插件或端口声明无效时，显示缺口并禁止直接应用。默认参数须被插件 schema 接受。
- 只自动连接类型兼容且来源唯一的输入。多个候选来源、互斥输入模式和缺失输入留给用户确认，提交检查阻止未绑定的必需输入。
- 预览与执行复用 `compute/scripts.py`；预览保留实际 `ssh` 或 `presigned` 暂存模式。预览中的任务 ID、运行目录和签名 URL 是占位值。
- 生产环境强制插件声明有效、当前声明有运行验证。开发/验收环境可设 `BDA_V2_COMPUTE_REQUIRE_RUNTIME_PROOF=true` 开启同样门槛。验证证明仍需运营人员在客户环境检查其适用性。
- LSF 必须配置 SSH 主机和远端工作目录。静态 preflight 的 `connectivity_checked=false`，不代表已做实时连通性检查。
- 连接成功本身不提交作业。确认提交产生 submission/job/outbox，worker 才调用适配器；LSF 通过 `bsub` 提交。
- 提交携带预览时的工作流版本；工作流变化返回 412，需重新检查。已提交的工作流不接受第二个提交；同一幂等键重试返回原结果。失败作业使用重试入口，新的方案使用新的工作流。
- 提交同时核对每个计算节点的预览指纹，涵盖脚本、插件声明、输入及执行站点。预览后插件、参数或站点改变会返回 412，要求重新预览。插件声明在提交事务期间加读锁，再保存执行快照。后续部署环境变更仍须按运维规则管理。
- Qiming 的 CPU/GPU、队列、输入清单和登录规则仍以 [集群操作规则](QM_CLUSTER_OPERATION_RULES.md) 为准。

## 独立实验工具

顶部“工具箱”进入 `/tools`。无需选项目即可使用浓度、稀释和单位换算，或预览 BLI、AKTA、酶动力学仪器数据。

仪器预览不创建 artifact 或实验结果。文件限制为 12 MiB；压缩包展开限制为 64 MiB。随仓库提供的 Nginx 和 Helm 配置仅对预览路径放宽到 17 MiB 请求体，以容纳 base64 和 JSON；外部网关也须配置对应上限。预览后选择项目，再点击“保存到当前项目”，原始文件走现有对象存储上传流程，分析结果带版本与来源写入项目。变更文件或分析参数会清除旧预览。仅在项目实验页执行分析时，默认直接保存项目记录。

`POST /wetlab/analysis-previews` 是经过身份验证的临时计算接口，接收受限的编码数据，不承担持久化上传。持久化文件仍遵循 browser-direct 上传契约。

## 客户部署验收

本地回归验证状态规则和接口交接，浏览器夹具验证交互，不替代真实运行验收。交付前应使用测试项目完成：

- 客户提供的强模型及较弱模型分别起草任务书、检索中英文主题、保存可追溯的待审核文献笔记，并给出适用模板或明确拒绝推荐。
- 网络超时、模型无效 JSON、无检索结果、缺输入和插件证明过期时，用户能看到原因并恢复。
- 客户批准的小型任务经预览确认后只产生一个外部作业，记录队列、资源和调度器 ID；验证取消、重试、断线恢复、产物校验和结果回收。
- 用仪器测试文件核对预览与保存结果一致、来源关联可追溯，并验证不同项目的权限隔离。

当前模板目录的覆盖范围有限，不能承诺任意研究类型都能自动生成完整可执行方案；目录、插件和客户环境验证应随交付场景扩充。
