## 本次修复清单

1. 研究室聚焦视图高度无上限，长答复将输入区推到页面底部：限制记录区域高度并把输入区前置，桌面和移动端均检查位置与换行行为。
2. 设计反馈修订后，人工执行完成仍把已替换的无效结果计入：仅使用当前有效反馈判定状态，旧反馈继续可查。
3. 反馈修订可以指向不同问题：要求同一冻结评审、同一问题；反馈与人工完成使用一致的工作流/项目锁顺序。
4. 新设计学习按钮未显式指定类型：补齐 `type="button"`，防止嵌套表单误提交，并符合 UI 控件约束。
5. 新设计表缺少数据流矩阵登记、指南缺少元数据和索引：补齐契约和文档入口。
6. 页面壳测试错误地把新增的固定页头当成内容区：改为检查主内容真实父容器，仍保留滚动和最小宽度约束。
7. 三份归档文档被导航修复改写，违反保留原字节约定：恢复 Git 历史中校验匹配的正文，现行文档链接保留在归档说明中。
8. 浏览器夹具缺少设计学习 API：补充明确的合成空状态；不以通用成功响应掩盖未知接口。

## 验证方法与边界

- 需求完整性：以上逐项对照近期界面、记录、隔离、调用控制和门控要求。
- 逻辑正确性：核查反馈修订、冻结评审、历史保存和权限边界；回归测试保留纠正前后的观察。
- 边界情况：长答复、移动宽度、换行、只读、接口失败、项目切换、空记录和错误问题修订。
- 代码质量：TypeScript 构建、Ruff、mypy、lint、OpenAPI 契约、文档清单、公开数据边界和精确镜像检查。
- 测试覆盖：前端全量测试、后端关键链路与独立 PostgreSQL 测试库、90 场景浏览器矩阵和 Bot 专项浏览器检查。
- 实际运行：本地数据库恢复后，检查现有项目页面、报告、复核、输入框和导航；不发送模型请求、不重跑科研任务。

临时测试数据库和浏览器夹具均独立于科研数据。工作树整理保留其他任务的未提交文件，不执行全仓库清理删除。main 合并继续遵守 CI 和外部审阅要求。
