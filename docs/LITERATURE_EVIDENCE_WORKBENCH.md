## 结论与选择

BDA 应以“一个项目论点 + 一段可回查原文 + 一条有边界的解释”为最小整理单元。书目用于管理来源，摘录用于核查文字，论据解释说明这段文字为何与项目有关。三者不能用一段 AI 摘要替代。

这次选用 **Zotero 的阅读组织 + Hypothesis / W3C 的原文锚定 + SciFact 的论点—证据关系 + ASReview 的人工筛选留痕**。这是方法组合，代码在 BDA 内实现；没有安装这些服务，也没有把项目文献发送给它们。

## BDA 原有缺口

现有存储已有 document / chunk / claim / evidence / retrieval trace，具备来源追溯基础。但自动索引主要按句拆分；这只能给出待阅读文字，无法解释它支持哪个项目判断。文献目录和综述引用分离，原文位于多层展开项，技术标识比科学逻辑更突出。

旧记录只有题录、DOI 或网页链接时，不能补写一个看似真实的原文。题录元数据核验、原文匹配、论据人工复核、项目实验验证是四件不同的事。

## 每条论据必须回答什么

1. **我们的论点**：写一个可被支持或限制的具体判断，避免“这篇文章很有价值”这类空泛描述。
2. **论文原文**：保留原语言、原文字，不把翻译或模型改写放进引号。附论文链接、章节/页码/图表位置；有已存片段时记录精确位置。
3. **论文观点**：作者实际上观察到什么；这是整理者对原文的概括，与原文分栏。
4. **提供的论据**：作者结果如何支持、限制或仅为项目提供背景；从文献到项目的外推必须写明。
5. **适用边界**：物种、实验体系、剂量/条件、统计不确定性、相关性与因果性、尚未验证的迁移。

例如，“在某实验条件下结合提高”可以支持设计一个对照实验，不能自动推出“候选物在人体有效”。相反结果应归在同一个论点下，不能因不支持路线而从资料库消失。

## 本次实现

- Research → 文献采用目录与阅读区布局；可按标题、作者、DOI 查找，筛选尚未整理的文献。
- 论据卡把原文、论文链接、作者观点、项目解释与边界直接呈现；支持按论点跨文献对照和搜索。
- 可从已存片段选中文字，或粘贴精确原文；后端按文字匹配，重复出现时需要具体起点。Unicode 位置以字符而非 JavaScript UTF-16 单元计算。
- 只有题录的文献可按 PMID / DOI 请求摘要和可获得的开放全文，沿用现有队列、原始响应制品及检索留痕。检索不自动编写论据。
- 缺少已存片段时可录入手工摘录，但始终标为未匹配，不继承题录“已核对”的标签。
- 内容编辑重置为待复核；认可、排除、重新复核均持久化。保存与审阅使用当前版本的 If-Match，过期返回 412，不自动覆盖别人的修改。
- 导出当前显示的论据为 Markdown，携带链接、引文、解释、边界、状态及来源 JSON。分页未加载完全时明确显示统计不完整。
- 旧题录和自动拆句保留；不会把它们批量升级成已认可的项目论据。已有项目论文仍需要逐条完成科学整理。

## 存储与校验

沿用 `literature_claims` 和 `literature_evidence`，不新建同义来源库。显式整理的记录使用 `curation_kind=argument_evidence_v1`：claim 存项目论点，attributes 存作者观点、解释、关系与边界；evidence.content 存原文，source_ref 存来源与 selector。自动拆句和专利权利要求不会混入论据视图。

按论点对照目前按完全相同的论点文字聚合；编辑器可以复用已有论点，分组显示支持、反驳和背景的数量，每篇文献的卡片仍独立审阅。近义论点不会由模型自动合并。未来可新增显式论点实体和研究决策链接，但应先完成真实使用反馈，避免生成重复的项目结论层。

保存时校验片段属于该文献、原文逐字匹配、起止位置有效；链接限定 HTTP(S)，拒绝内嵌凭据。读取时重新核对片段版本、文字 checksum 和引文位置。源内容变化时保留旧摘录，标记待重新定位，并禁止直接认可。正文编辑和审阅的前后快照与操作者进入同事务审计记录。

原文匹配只证明“摘录来自保存的文字”；不证明出版社版本永不变化，也不证明科学论点正确。手工页码/章节属于作者输入，当前不自动核验。读取 API 有项目隔离，写入需项目 researcher 或以上权限，UI 还遵守演示只读状态。

Copilot 和 Intelligence 接收论据时，作者观点、项目论点、关系、解释、边界和原文状态分别传递；项目论点不得以“论文声称”的身份传入模型。普通自动拆句列表不混入这些记录；引用详情保留论据与边界。

## 下一步的优先级与评估

优先级一是按真实项目逐条建立可复核论据，处理相反结果和外推边界。然后再考虑 GROBID/PDF 坐标、Zotero 的导入/同步、CSL/BibTeX 标准导出、独立论点实体。大规模系统综述确有筛选负担时，再评估 ASReview 的主动学习排序。

评估指标建议使用：链接可达率、原文匹配率、引用支持关系的人工一致率、缺少边界的记录比例、找到原文的用时、反证覆盖和一次论点修订所需时间。不能把摘录数、token 数、智能体数或“已认可”数量当成科研效果；自动化上线前需要带反例的人工标注样本进行评估。

## 本次验收范围（2026-10-11）

本地公开 PD1 预览项目的 12 篇论文已整理为 12 条待复核论据：6 篇有已获取的开放全文，6 篇只有摘要；12 条摘录均与保存的文字精确匹配。支持、限制和背景证据按 5 个项目论点归组。它们是整理草稿，不是人工认可或新的实验结论；不表示私有历史项目已经全部整理。运行数据和导出留在本地，代码仓库只包含功能与方法说明。
