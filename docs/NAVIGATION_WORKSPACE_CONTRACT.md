# 全局导航与工作区入口契约

状态：活跃

最后核验：2026-10-11（导航、Research 与 Bots 相关自动化回归及 TypeScript 检查）

权威范围：主导航、工作台分组、帮助入口、Research 决策记录和文献任务交接的前端 URL 与交互契约；不替代后端权限或执行授权。

数据来源：`frontend/src/lib/nav/routes.ts`，Topbar、HelpMenu、CommandPalette、Research、Bots、ResearchDecisionCenter 的实现及对应回归测试。

替代关系：取代 [项目引导](GUIDED_PLATFORM_WORKFLOW.md) 和 [Bot 工作区](BOT_FIRST_WORKSPACE.md) 中旧的独立工具箱按钮、主菜单 Timeline 与内嵌文献任务入口说明；上述文档的历史验收记录继续保留。

## 主导航、工作台与帮助

主导航依次为项目、待我决定、研究团队、研究、实验工具。实验工具使用独立地址 `/tools`，未选择项目时也可进入。

工作台菜单和命令面板复用同一分组：

| 分组 | 地址 |
| --- | --- |
| 计算设计 | `/workflow`、`/candidates` |
| 实验学习 | `/lab`、`/learning`、`/results` |
| 平台 | `/extensions` |

不同屏幕尺寸均只有一个帮助入口，包含界面导览、使用指南和 FAQ。FAQ 不再出现在主导航或命令面板中。`tour-help` 导览标记属于帮助按钮。旧的顶栏 Toolbox 按钮及移动端工具箱副本已移除。

## 研究页与唯一决策记录

Research 显示研究页标题，项目身份由全局项目选择器提供。目标页首先展示决策中心，目标树通过“管理问题与目标树”明确展开。任务书使用唯一的 `ProjectBriefPanel`，放在目标页“研究背景与任务书”折叠区，默认收起，避免反复展开整段内容。

项目列表的打开链接和研究室的“查看项目简报”统一进入 `/research?project=…&tab=goals&brief=1`，显式展开上述折叠区。普通目标页不自动展示任务书；直接链接、刷新和只读身份使用同一面板与权限控制。

决策中心最多展示最近三条历史记录的标题与结论索引，完整推理统一位于 `/research?project=…&tab=timeline`。旧 `/timeline` 地址兼容重定向到该标签，不保留第二份时间线页面。时间线分区外层保留 `data-tour-id="research-timeline"`，内层保留 `data-tour-id="timeline-page"`，分别兼容研究导览与旧时间线浏览器验收定位。

主动切换研究标签会增加浏览器历史记录，支持后退；旧别名和默认标签的规范化使用 URL 替换。项目及其他上下文参数保留。

## 文献任务交接

研究页的“准备 AI 文献调研任务”进入唯一的 Bot 任务工作区：

`/bots?project=…&view=tasks&service=literature&draft=…&draft_project=…&from=references`

- `draft` 是可编辑的任务文本，接收时最多使用 4000 字符。
- `draft_project` 必须匹配解析后的当前项目；切换项目不会套用另一个项目的传入草稿。
- 该入口只识别 `service=literature`；服务提示不构成执行或工具授权。
- 没有现存任务草稿时，Bot 页将其放入按项目隔离的浏览器状态，打开计划预览，授权写入列表为空。
- 已有未提交草稿时，先保留原稿，由用户选择保留或替换。保留原稿还会清除传入的服务提示。
- 接收或放弃后，通过 URL 替换移除传入文本参数。任务标签与运行记录选择继续保留既有历史行为。`from` 规范化为合法 Research 标签，并生成带项目范围的返回链接。
- 导航不会启动任务、模型评估、文献检索或其他写入。用户仍须检查计划并操作现有启动控件。

此导航契约不引入 API 或后端数据模型变更。

## 功能归属

| 使用目的 | 唯一完整工作区 | 其他页面的呈现方式 |
| --- | --- | --- |
| 项目身份与任务书 | 研究目标页的任务书折叠区 | 全局项目选择器提供身份；项目列表与研究室链接到同一完整面板 |
| 提交任务、查看 Bot 执行 | 研究团队 | 文献页传入可编辑草稿，需用户检查后启动 |
| 论点、论文原文、论据 | 研究的文献分区 | 决策和任务通过证据引用关联 |
| 路线与决策推理 | 研究的决策记录 | 决策中心保留最近三条索引，方法页保留“查看决策记录”链接 |
| 通用实验计算与文件预览 | 独立实验工具 | 项目实验页只提供入口链接 |
| 构建体、已保存仪器结果、人工质控 | 项目实验 | 工具预览保存后链接回所属项目 |
| 实验批次、模型评估、下一轮选择 | 项目学习 | 通过项目上下文连接实验结果与决策 |

独立工具的分组、计算条件和保存行为见 [实验工具使用与计算约定](LAB_TOOLS.md)。方法页不再请求或绘制第二份决策树。
