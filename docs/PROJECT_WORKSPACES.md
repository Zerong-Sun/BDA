# 项目空状态、草稿编辑与历史兼容

2026-10-12。适用于当前应用模式；演示模式仍只读。

## 浏览和执行分别判断

选定项目后，Research、Workflow、Candidates、Lab、Results 均可打开。进度条根据已有记录显示进度；缺少目标、计算结果或实验数据不再锁住后续页面。没有项目时仍需先选择项目。

Workflow 允许目标未就绪时创建、重新打开和编辑草稿，也允许先上传项目资料。提交计算仍要求目标确认、计算权限、输入与执行预检通过；已提交流程保持只读。Manage 返回带项目上下文的项目页。

“添加节点”可以选择模型计算或人工审阅步骤。人工步骤记录名称、输入、来源及验收条件，明确保存为 `execution_mode=manual`、草稿及待审阅，不会调用模型或记录完成。模型注册表不可用时仍可添加人工步骤。

## 手动候选和实验记录

Candidates 默认展示全部来源数据集。空页提供手动候选入口，候选要求名称和设计依据，序列与来源链接可选。只接受 HTTP(S) 来源及标准氨基酸序列；新记录为提案、待复核、未实验，无虚构分数。

候选详情支持补充依据和来源，更新使用版本条件。如果已有序列需要更改，应新增候选，保持历史结构和实验来源一致。跨项目切换清除旧候选、节点、流程和数据集筛选参数。创建失败保留表单，权限读取失败可重试；只读用户和演示模式不允许写入。

蛋白库允许手工登记或导入 FASTA；从候选登记的构建体保留返回候选的链接。空 Results 页面继续提供实验文件导入入口。构建登记与模型评分不等同于实测结果。

## 历史数据规范化

`app/workflows/legacy.py` 提供受限维护服务：只把未提交草稿的旧节点状态 `not_started` 改为当前 `draft`，保留 ID 与参数、递增版本并记审计。服务拒绝跨项目、过期版本、非草稿及存在任何作业/提交的流程；调用者负责权限和事务提交。它不是自动兼容所有未知状态的运行时回退。

旧节点缺失当前插件绑定、目标身份不清或历史运行状态无法核实时，保留原始记录并作为待复核项。不要批量映射插件、重跑任务或将历史状态伪装成当前成功结果。
