## 当前交付边界

公开演示包只包含可分发的 PD1 参考资料与合成夹具。导入时安装的四组对话为编辑版预设，界面明确标识，不调用模型或执行工具；重复导入保留编辑后的对话。用户实际科研项目、仪器文件及实验室报告属于各自数据空间，不随公共软件分发。

资料库、项目角色、计算连接和科研放行是四个独立条件。用户可以先建项目、保存草稿和补资料；提交计算仍检查目标输入、参数、插件资格、脚本审阅和门控。演示完成、模型任务结束及实验功能成立不能互相替代。

## 从新项目到下一轮学习

| 步骤 | 用户完成的工作 | 完成依据 |
|---|---|---|
| 项目定义 | 写明对象、问题、预期结果和停止条件 | 保存的任务书与目标 |
| 证据整理 | 保存来源、阅读范围、论点、原文及适用边界 | 可回到来源位置的证据卡；书目不冒充全文 |
| 数据准备 | 连接序列、构建、候选与原始数据；区分空值和零值 | 有项目归属的制品及校验值 |
| 流程草稿 | 选择工具、连接输入输出、定义筛选规则与人工审阅门 | 保存的流程版本；缺项可编辑但不得绕过提交检查 |
| 执行审阅 | 核对实际脚本、模型版本、输入、计算身份与资源 | 与当前版本匹配的预览指纹 |
| 执行与收集 | 跟踪确定性作业身份，核对终态与输出清单 | 文件数量、大小、SHA-256、解析结果与谱系 |
| 决策与学习 | 区分支持、反证和无法判断，记录对下一轮的影响 | 关联原始证据的决策与有适用范围的经验 |

门控错误、缺少测量和测得不合格分别记录。没有合格记录的必需输入不能伪装为下游成功；人工门未决定时保持等待。结果采集使用与实际调度器隔离的适配器契约，因此可以自动测试调度、筛选和恢复逻辑；真实站点仍需单独验证。

## 文献与表格的使用规范

自动切句得到的是待审阅原文候选，不是已证实论点。纯年份、图号碎片和同文献的重复句不再生成新论点；完整段落保留。已有确定性质量排除项仍可在文献详情中核对，默认论点列表和 Bot 的证据上下文不再使用它们。被标记不适用于项目的文献保留书目和排除理由。

一般 `dataset` 和 `data_table` 条目进入“研究→数据”。数字、布尔值、数组和嵌套字段都可显示，空值保留含义；原始文件用实时授权链接下载。JSON 下载反映保存的数据，原始 CSV/工作簿用于核对类型与处理方式。多个文件可在同一交付目录中下载，不把文件名或附件清单当作数据已被读取的证明。

较大的数据表默认每页 25 行，可切换每页行数；搜索和排序覆盖整张已加载数据表，JSON 下载包含保存的完整数据。表格分页不等于后端文献/执行记录已读到最后一页，两类分页分别保留计数。

文献图、表、数值及补充材料分别保留覆盖状态。图像没有目视检查、补充文件没有读取、仅取得摘要或只提取部分段落时，继续显示缺口。表格数值须连接原文定位、单位、条件、对照、样本量和误差类型；未知字段显式为空。结构置信度、模型能量和仪器拟合值不自动成为实测功能标签。

## 多人使用各自启明账号

现有适配器支持指定计算目标，但当前产品没有个人连接注册、选择和路由界面。注册 BDA 账号不会建立 SSH 登录，登记一个 compute node 也不会切换执行身份。公开发布时必须如实呈现这一边界。

已落实的保护是：Public 默认禁止所有账号使用部署的 LSF 身份，Private 默认仅允许管理员；管理员可以用 `BDA_V2_LSF_SUBMITTER_USER_IDS` 显式授权使用同一部署账号的用户。项目权限本身不能借用该账号。新作业保存目标快照，之后更换部署连接不会把旧任务的状态查询、收集或取消发往新账号。

当前可运行的个人接入方式是每人使用独立部署及计算 worker，复用相同软件和流程契约，独立保存数据库、对象存储命名空间、密钥、SSH 会话和队列配置。使用者亲自完成 VPN、SSH 与 MFA；站点管理员验证插件和资源限制。需要团队协作时，通过明确的数据导出/导入分享经过审阅的项目资料。

长期通用方案采用个人执行连接器：

1. 连接器在用户能访问集群的本机或实验室主机运行，主动向平台领取已授权任务；平台不接收个人密码。
2. 配对码短时有效、只能使用一次。连接记录绑定 BDA 用户、组织、连接器公钥、站点和权限范围；换组织不自动继承。
3. 提交明确选择“我的连接”或获授权的实验室服务连接。服务端同时校验项目执行权限、连接所有者/授权、资源上限和对应站点的运行资格。
4. 任务签名绑定用户、项目、流程版本、插件、输入哈希、门控版本、资源上限和连接 ID。领取、取消和结果回传都验证范围，防止连接器替其他用户执行。
5. 连接器只复用用户已建立的会话；会话过期返回需要登录，暂停执行并保留任务。恢复先查询既有调度器身份，防止重复提交。
6. 输出以项目限定的短时上传授权回传，校验后进入现有收集和门控链路。撤销连接、用户退出团队、凭据轮换和连接器更新均保留审计。

这套连接器协议是后续设计，不是本次已交付的个人云路由功能。上线前应完成双用户交叉访问、同 ID 伪造、重放、断线恢复、撤销、取消、输出污染及按站点运行资格的真实验收。现有 allowlist 不能替代这些能力。

## 发布验收清单

- 代码、生成契约、迁移、数据流清单和 Public/Private 同步策略一致。
- 新建项目、空状态、只读用户、快速切换项目及错误恢复在浏览器中验证。
- 门控通过、失败、缺字段、空结果、人工等待与版本过期均有回归。
- 账号默认隔离，公开用户不能调用部署所有者的计算身份；敏感内容不进入公共仓库。
- 公开界面提供管理员联系/恢复路径、许可与数据使用说明；恢复邮箱未部署时不得宣称已发送邮件。
- 真实计算站点完成提交、排队、收集、取消、网络中断与恢复的验收；没有连接时明确记录未验收。

工作区整理保留各分支和未提交修改的恢复材料。公开软件与私有科研资料分别保存；本地测试和部署就绪不代表已经完成远端发布或全部科学验收。

## 2026-10-24 本地软件验收

PostgreSQL 隔离库全量测试 3,101 项通过、11 项按夹具可用性跳过；总体分支覆盖统计 87.83%，核心模块覆盖门禁通过。迁移升级、模型漂移检查和回滚通过。前端 207 个测试文件共 1,407 项通过，生产构建及入口体积门禁通过。

浏览器基础矩阵 90/90、工作区断点 19/19、Bot 交互 8/8 通过；加入大表分页后，研究页 9/9 场景再次通过。模拟 API 用于界面回归，实际项目另行检查静态演示标签、表格行和授权下载。真实计算站点与个人连接器未在本轮验收。

工作区使用固定侧栏与窄屏页面菜单；设置将即时外观偏好和需要保存的项目模型配置分开。终止任务可准备新草稿，保留原记录并清空写入授权；取消请求在每一步之间获得执行锁，读取最新状态后处理，保留已经完成的结果。新任务仍遵循当前平台最多六次模型调用的限制。
