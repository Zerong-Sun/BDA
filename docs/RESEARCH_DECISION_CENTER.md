# 研究决策中心与项目学习记录

状态：活跃

最后核验：2026-10-11（本仓库实现与自动化测试）

权威范围：Research 目标页的决策定义、文献关联与历史呈现；不替代实验验收或学习模型晋升。

数据来源：`research_goals`、已整理的文献论据、`project_timeline_entries`；展示用户实际保存的记录，不自动补写研究事实。

替代关系：补充 [研究记录结构](RESEARCH_RECORD_STRUCTURE.md) 和 [文献论据工作台](LITERATURE_EVIDENCE_WORKBENCH.md)，继续使用原目标树与决策时间线。

## 入口与阅读方式

Research → 目标与问题首先显示决策中心。选择一个具体问题，依次阅读待验证假设、备选方案、成功标准、反证/停止标准、下一次决策及其触发条件。选择保存在 `?goal=<UUID>` 中，分享链接时仍保留项目范围。

右侧检查的是记录完整性：有没有定义假设、至少两个选项、正反标准、下一次决策，以及关联论据能否找到、是否已复核且与保存原文匹配。这些检查不计算科研成功率，不自动判定继续/停止，也不会因为目标状态为 `answered` 就认定实验成功。

未填写的标准明确显示为缺口。旧目标默认空定义，不从既有任务书或 prose 中猜测标准。用户可以先保存不完整定义，逐步补齐。

## 文献与正反论据

每个目标显式选取文献工作台的论据卡 ID。整篇论文或整个资料库不会自动成为某个假设的支持材料。页面同时展示论据自身的项目论点、支持/反驳/背景关系、原文、解释、边界及论文链接；关系始终针对论据卡内的断言，不能省略该断言后将关系偷换成对目标假设的直接证明。

只有本项目中真实存在的已整理论据可被保存为关联。题录、自动拆句、其他项目中的论据及不存在的 ID 均被拒绝。仍未加载的分页论据与加载完整后不可用的引用分别显示；请求失败也不冒充“没有证据”。相反结果和已排除的论据仍能被查看，其状态不会因选入目标而改变。

## 项目学习记录

下方只读呈现现有时间线中最近三条 decision、result、method、resolution 的索引，保留实际时间、标题、已记录 outcome、决定者归属和 supersedes 关系。完整摘要、原始决策、备选方案及其未采用理由统一在研究页的“决策记录”标签中管理。已关联当前问题的记录也通过标题链接进入该唯一详情入口，避免在目标页重复展开整份历史。

这是“项目记住了哪些观察与判断”的阅读入口；不会把记录数量当作学习增益，也不会为无记录项目生成学习结论。原时间线的新增或修改会使决策中心共享的查询缓存失效，无额外复制或自动写入。

## 数据契约、权限与迁移

`ResearchGoalCreate`、`ResearchGoalUpdate`、`ResearchGoalResponse` 增加可选 `decision_contract`，对应 `research_goals.decision_contract` JSON 字段：

- `hypothesis`：最长 3000 字符。
- `alternatives`、`success_criteria`、`falsification_criteria`：各最多十项，每项 1–1000 字符，去首尾空白后必须非空且不重复。
- `next_decision`：最长 2000 字符。
- `evidence_note_ids`：最多一百个不重复的 UUID，逐次写入校验项目归属与论据类型。

嵌套字段拒绝未知键。旧补丁省略或将 `decision_contract` 置为 null 时保留既有内容；传入空对象可明确重置为未填写定义。读取旧记录不补写数据。没有新增第二套目标或论据表。

迁移 `0074_research_decision_contract` 从 `0073_learning_lifecycle` 增加非空 JSON 列，旧行默认空对象；降级删除该新增列，不改原有目标、文献与时间线。上线需先执行现有备份和迁移流程。

编辑复用原目标补丁接口和权限，需当前 `If-Match`。API 加锁后检查版本；编辑器固定打开时的版本，后台刷新不会替旧草稿悄悄换成新版本。过期保存返回 412 并保留用户草稿。合同更新的前后内容、操作者、项目与新版本写入同事务审计。只读角色和演示模式不显示编辑入口。

## 验收与边界

后端测试覆盖旧目标默认、部分补丁保留、版本冲突、审计、严格输入校验、跨项目论据拒绝、权限及既有目标树/决策树回归。前端测试覆盖原文与反证可见、标准与历史并读、版本保持、失败/分页未知状态和只读模式。

当前不自动求解决策价值，不计算实验成功概率，不从论文推导项目结果，不修改模型/实验/候选数据。可量化的预注册实验标准、实验结果验收与模型评估应继续由各自领域管理，再由研究者在时间线记录决策。
