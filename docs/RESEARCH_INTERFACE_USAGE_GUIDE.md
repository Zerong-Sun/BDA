# Research 界面使用逻辑指南

状态：活跃

最后核验：2026-08-29（Asia/Shanghai；本轮核验格式、索引与链接）

权威范围：本文标题所述主题；平台总览与成熟度以仓库根目录 `README.md` 为准。

数据来源：仓库内版本化代码、配置、测试与本文列明的来源。

替代关系：如正文未另行声明，则不取代其他权威文档。

## 1. 界面目标

Research 是当前项目的研究档案，不是独立项目生成器，也不提供脱离项目的关系可视化入口。用户先选择项目，再在同一个项目上下文中完成综述、证据审核、文献核验、结构确认、数据比较和方法记录。

后端聚合接口 `GET /api/v2/projects/{project_id}/research-workspace` 是页面唯一展示数据源。静态研究包只负责首次同步与版本补齐，不直接参与渲染。

## 2. 固定使用路径

1. 在项目选择器中选择唯一的活动项目。
2. 在“综述与证据 / Review & Evidence”阅读项目综述，检查证据声明并补充项目笔记。
3. 在“参考文献 / References”核验论文元数据、摄取状态和声明审核状态。
4. 在“PDB 结构 / PDB Structures”确认结构来源、实验方法、分辨率和准备状态。
5. 在“数据表 / Data Tables”比较候选、评分、计量和结构化研究数据；需要追溯时下载原始 JSON。
6. 在“研究方法 / Research Methods”查阅检索策略、验证说明、字段字典和本体，并维护精选知识。
7. 证据足够后，将项目目标和已审阅笔记转入 Workflow。

五个标签是同一项目档案的五种视图，不创建新项目，也不复制研究正文。

## 3. 页面结构

页面从上到下保持四层：

1. **活动项目条**：只负责切换项目。
2. **项目摘要**：项目名称、摘要、研究包版本、证据日期及关键计数，只显示一次。
3. **当前标签主内容**：只显示该标签负责的数据。
4. **当前标签操作区**：只保留该标签对应的写操作或外部工具，并默认收敛复杂工具。

禁止在一个标签中再次嵌入其他标签的完整面板。相同综述、证据、文献或结构记录不得在同一页面重复渲染。

## 4. 五个标签的职责

### 综述与证据 / Review & Evidence

- 主内容：项目综述正文、已保存的项目笔记、可审核的证据声明。
- 操作：添加项目笔记、请 Copilot 补充所选章节、生成同类研究、转入 Workflow。
- 展示规则：综述正文只出现一次；关系数据按“主体—关系—对象”的证据声明展示，不单独渲染节点目录或关系画布。

### 参考文献 / References

- 主内容：后端文献卡片及作者、期刊、年份、PMID、DOI、核验和摄取状态。
- 操作：文献摄取与声明审核。
- 展示规则：不重复项目综述、项目笔记或证据摘要。

### PDB 结构 / PDB Structures

- 主内容：后端 artifact 与 target 关联的结构列表、查看器、方法、分辨率和状态。
- 操作：靶点确认、结构检索、导入、上传与准备。
- 展示规则：不存在结构时显示空状态，不用静态包结构代替。

### 数据表 / Data Tables

- 主内容：候选排序、评分、文献计量和其他结构化数据集。
- 操作：行筛选、下载原始 JSON、展开高级 JSON。
- 展示规则：默认展示双语列名与单元格；原始 JSON 不直接占据主界面。

### 研究方法 / Research Methods

- 主内容：方法、检索策略、验证报告、schema、字段字典和本体。
- 操作：精选知识编辑。
- 展示规则：不重复候选表、文献卡或证据声明。

## 5. 双语规则

- 切换语言不重新请求 workspace；接口一次返回中英文。
- 内置研究包在英文模式下必须显示英文项目名、摘要、正文、表头和结构化单元格。
- 普通项目或 Copilot 项目缺少当前语言时显示原文，并在页面顶部显示一次回退提示。
- PMID、DOI、PDB ID、UniProt accession 和论文原始题名可以保留原文。
- 用户新增内容记录当前界面语言作为来源语言，不自动调用翻译模型。

## 6. 项目与缓存规则

- 项目列表以后端为唯一权威；前端不猜测哪一条重复记录更完整。
- 内置托管项目按组织、研究包族和来源项目键保留真实数据最完整的一条，其余进入可恢复的软删除状态。
- 普通同名项目不参与内置项目清理。
- 所有 Research、Knowledge、Literature 查询键必须包含 `projectId`。切换项目后，旧项目数据不能短暂显示在新项目下。

## 7. 状态与验收

每个标签都必须具备 loading、error、empty、retry 和 mutation 后刷新状态。验收时在中英文模式分别访问五个标签，并用稳定记录 ID 或标题断言：

- 项目综述正文只出现一次；
- 同一证据、文献、结构和数据集在所属标签只出现一次；
- 英文内置项目无中文界面或可翻译正文；
- 单语项目显示一次原文回退提示；
- 旧的或未知 `tab` 参数立即规范化为 `tab=evidence`；
- 完全关闭并重新打开应用后，内置项目仍各只有一条。
