# 科研记录结构：以大麻素项目为样本的改造提案

状态：活跃

最后核验：2026-08-29（Asia/Shanghai；本轮核验格式、索引与链接）

权威范围：本文只描述公开平台的研究记录结构，不包含任何私有项目状态或实验授权。

数据来源：仓库内版本化代码、配置、测试与本文列明的来源。

替代关系：如正文未另行声明，则不取代其他权威文档。

本文用一个真实项目当检验标尺。大麻素 binder 项目在集群上跑了 5 个设计作业、3 个验证
作业，产出 22 个候选、102 条指标，完整经历见
具体研究项目的设计与运行记录应保存在其授权的数据仓库中，而不是公开软件仓库。

做法是**先把数据往平台里接，接不进去的地方才是要改的地方** —— 而不是先设计 schema
再找数据来套。下面每一条都标注了它是被哪件真事逼出来的，以及当前状态。

## 0. 这个项目的科研叙事长什么样

改造的目标不是"能存下数字"，而是能承载下面这条链 —— 因为这才是科研记录真正的形状：

| 阶段 | 内容 | 产出 |
|---|---|---|
| 观察 | P1 试点 0 个候选，9 个 cycle 的 ipTM/pLDDT 达标却全卡丙氨酸门槛 | **阴性结果** |
| 假设 | 丙氨酸塌缩源于全 X 起手（`percent_x=90`），不是模型固有权衡 | 假设 |
| 检验 | 单变量对照：只改 `percent_x` 90→50，其余逐字节相同 | **对照臂** |
| 结果 | 候选 0 → 4，丙氨酸中位数 28.7%→21.8% | 支持假设 |
| 复现 | 同参数独立重跑 | 4 → 14 个候选，**方向可复现、产额不可复现** |
| 独立验证 | AF3 重新预测复合物 | 10/18 通过；**与 Boltz 秩相关仅 +0.28** |
| 证否 | 四配体阴性对照 | **Δ 中位数 −0.04 —— 通用疏水口袋，不是 THC 结合蛋白** |
| 方法改造 | fork 上游，使接触约束可指向配体原子 | 新对照臂 |

**这条链里最有价值的三项是阴性结果、对照关系、独立性**。当前 schema 三项都存不住。

## 1. Candidates：分数必须带"谁打的"和"针对什么"

### 已实现

**问题（真事）**：把选择性数据往里接时直接撞墙。同一个候选被 AF3 对 5 个配体各打一次
ipTM，而 `candidate_metrics` 的唯一键是
`(candidate_id, metric_key, method, model_variant)` —— 五行完全相同，**互相覆盖**。
`context` JSON 能放配体名但不在键里。也就是说，**平台今天存得下"这个设计 0.94"，
存不下"它对对照也 0.87，所以余量只有 0.07"**。而后一句才是决定要不要继续的那句。

**问题二（真事）**：Boltz 的 ipTM 头名候选，被 AF3 独立复评后掉到第 7；AF3 的头名在
Boltz 那里排第 8。两者秩相关 +0.28。**设计模型给自己打的分不是佐证**，但界面上它和
独立复评长得一模一样。`method` 也推不出来 —— 同一个模型在这个流程里是设计器，在另一个
流程里就是独立验证器。

**改动**（迁移 `0030_candidate_metric_assessor`）：

- 新增 `condition`，并**加入唯一键** —— 一个方法可以对同一指标按不同实验条件各报一次。
  存量行取 `""`，语义不变。
- 新增 `assessor`：`design_model` / `independent_model` / `experiment` / `unknown`。
  存量行回填 `unknown` 而不是按 method 猜，因为答案取决于该指标来自哪条流程。
- ProteinHunter parser 此前只写不可查询的 `scores` blob，现在同时产出 metric 行，
  一律标 `assessor="design_model"`，并按运行参数记录 `condition`（如 `ligand:TCI`）。

### 待做（展示层）

- **候选表不应出现裸分数列**。每个数字旁必须显示 assessor；`design_model` 的分数应有
  视觉降权（它是自评）。
- **默认排序不能用设计模型的自评分**。本项目按它排会精确挑错。
- 当某候选存在多个 `condition` 的同名指标时，展示应自动**并排**并给出 Δ，而不是只显示
  一个。选择性只在并排时才有意义。

## 2. Results：阴性结果与对照臂

### 问题（真事）

P1 试点产出 **0 个候选** —— 而这是整个项目最有信息量的一次运行（它定位了丙氨酸门槛
才是瓶颈）。当前 Results 面对 0 候选只会呈现为空状态，等同于"什么都没发生"。

另一件：本项目**所有**因果结论都来自运行之间的比较（px90 vs px50、复现、O1 臂）。
平台没有任何地方记录"这两次运行只差一个参数"。我当时只能手工 diff 渲染出的脚本来自证
单变量 —— 这个证据没有留在平台里。

### 待做

- **0 候选是结果，不是空态**。Results 应展示"本次运行 35 个 cycle，9 个达标，全部被
  丙氨酸门槛拦下"，并把门槛拦截原因分布画出来。判据来自 `summary_all_runs.csv` 这类
  全量表，而不是只看被提升的候选。
- **对照臂并排视图**：同一 lineage 的运行横向对比每个指标的分布，标出变动的参数。

## 3. Workflow：运行之间的血缘

### 问题（真事）

`workflow_runs` 之间没有任何关系字段。但本项目的三次 px50 家族运行里：
4083249 是 4083234 的**独立重跑**，4084328 与 4083234 **只差 `contact_residues`**。
这层关系是全部因果推断的基础，却只存在于我写的文档里。

### 已实现（迁移 `0031_run_lineage_outcome`）

`workflow_runs` 上加了三个字段：

- `derived_from_id`（自引用 FK）：本次运行以哪次为基线，创建时声明并校验同项目
- `arm_label`：`baseline` / `replicate` / `variant`
- `varied_parameters`（JSON）：`{节点: {参数: {from, to}}}`

**只有 `derived_from_id` 由人声明，另外两个由平台在提交时计算**（`compute/service.py`
的 `_record_lineage`，逻辑在 `workflows/lineage.py`）。这把"单变量对照"从一句自述变成
平台可验证的观察：作者说了什么不重要，记录里差了什么才算数 —— 一个被描述成单变量、
实际改了三个参数的运行会被如实标成 `3 parameters across 1 node(s)`。

在提交时而非建链接时计算，是因为链接建立后参数还能改；有意义的是**运行发生那一刻**的差异。

节点增删也算差异（加一个验证步骤和调一个参数一样改变了实验）；参数类型变化同样算
（`"50"` 和 `50` 传到 CLI 里不是一回事）。空 diff 即复现跑。

## 4. Research：可证伪的结论

### 问题（真事）

`research_findings` 只有 `finding_type` + 自由文本 `content` + `evidence` JSON。
本项目最重要的结论是**证否**（"这些设计没有选择性"），以及一次**被推翻的中间结论**
（"高 ipTM 必然伴随高丙氨酸"看似是模型固有权衡，后被 `percent_x=50` 推翻）。
自由文本存得下叙述，存不下"这条结论推翻了那条"。

### 已实现（迁移 `0031_run_lineage_outcome`）

- `outcome`：`supported` / `refuted` / `inconclusive` / `unspecified`，**带索引** ——
  "我们排除了什么"变成可查询的问题。`refuted` 是一等结果，不是失败态。
- `supersedes_id`：自引用，记录结论的更替。被推翻的中间结论留在记录里，不删除。
- `provenance`：`{"job_ids": [], "candidate_ids": [], "artifact_ids": []}`，
  用标识符而不是正文里提到的名字。

存量行回填 `unspecified` 而非猜测，理由与 0025 回填 `assessor="unknown"` 相同。
`supersedes_id` 校验必须同项目，且不能自指。

## 5. 生成提示：补上计算实验这一类

现有的 `SCIENTIFIC_REVIEW_PROMPT` / `GROUNDED_SCIENTIFIC_REVIEW_PROMPT` 在**证据纪律**上
已经很强（禁止臆造具体值、要求 checksum 级证据标签、区分事实/推断/假设、要求给证伪
实验）—— 那是甜味蛋白项目踩出来的，不要削弱。

但它们面向**文献综述**。计算实验有自己的失败模式，需要单独一套，至少覆盖：

1. **自评不得当作佐证**。凡引用某个模型对自身产物的打分，必须标注为自评，并禁止仅凭
   它给出排序或推荐。
2. **每个数字必须带 assessor 与 condition**。"ipTM 0.94" 不是完整陈述，
   "AF3 对 TCI 的 ipTM 0.94，对最强对照 0.87" 才是。
3. **阴性结果按原样报告**，不得软化成"有待进一步优化"。0 候选、Δ≈0 都是结论。
4. **因果主张必须指明对照臂**及其变动参数；没有对照就只能写成假设。
5. **区分方向可复现与量级可复现**。本项目 `percent_x=50` 的方向稳、产额从 4 到 14 差
   3.5 倍；把后者当承诺就是误导。
6. **样本量与方差要显式**。5 条 trajectory 的结论不能写成规律。
