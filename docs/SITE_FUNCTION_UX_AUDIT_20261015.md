# 全站功能与使用逻辑审查

状态：已实施；六维回归与运行验收记录。
最后核验：2026-10-15。
权威范围：本轮 Public / Private 访问、页面逻辑、前端样式和文献证据包的改动。
数据来源：版本化源码、自动化测试与本地浏览器/API 实测。
替代关系：补充既有项目工作区审查，不替代科学结论的人工审核。

日期：2026-10-15。范围：Public 匿名工作区、Private 登录工作区，以及项目、研究资料、Bot、Workflow、候选、实验、学习、结果、决策、工具、扩展和设置的主要路径。

## 页面职责与使用顺序

| 入口 | 主要职责 | 应承接的下一步 |
| --- | --- | --- |
| 项目 | 找到、切换和管理项目；按需打开详情 | 研究问题、资料或研究团队 |
| 研究 | 目标、文献原文与论据、结构、数据、方案、决策记录 | 交给 Bot 调研；建立 Workflow |
| 研究团队 | 角色职责、讨论、任务、交接；链接已保存报告 | 将产物写回对应研究页面，再审阅 |
| Workflow | 计算步骤、输入、参数、门控、作业和产物 | 候选筛选与实验准备 |
| 候选 | 设计、筛选、选择及设计依据 | 查看该候选的实验明细，或送入实验 |
| 项目实验 | 构建体、原始文件、分析版本及人工质控 | 结果审阅与学习数据 |
| 结果 | 仪器证据、计算证据、实验明细、结论和交付 | 决策记录、下一轮项目学习 |
| 项目学习 | 测定契约、数据冻结、模型验证、批次建议与回流 | 下一轮实验或项目交付 |
| 待我决定 | 集中呈现需要人工判断的事项 | 回到相应任务、证据或决策 |
| 实验工具 | 独立日常计算与仪器预览 | 可带入相关计算；明确选项目后才保存分析 |
| 能力与扩展 | 能力目录、运行条件和集成状态 | 管理员配置和验收 |
| 设置 | 外观、使用帮助、连接与授权配置 | 个人账号或项目模型配置 |

流程允许往返。工作区是否能打开，与是否允许提交计算、编辑或审核分别判断；没有内容的页面保持可浏览。Public 进入同一套完整工作区，无需账户；项目写入和 Bot 运行继续由 Private 与服务端权限控制。

## 修复清单

| 优先级 | 发现的问题 | 已实施的修复 |
| --- | --- | --- |
| P1 | 切换项目后，旧 artifact、residues、knowledge、goal 和文献任务草案参数可能保留 | 清除全部已识别的项目实体定位与任务交接参数，保留 tab、view 等视图偏好；Bot 会话仍按项目保存 |
| P1 | 打开无权限或已失效的项目链接时，可能悄悄显示之前选中的项目 | 明确链接优先；无效链接清空上下文，回到项目选择，避免把旧项目当成目标项目 |
| P1 | 项目读取失败会显示“未选择项目” | 共用项目入口区分加载、失败、空状态，提供原请求重试；研究页也使用该入口 |
| P1 | 仪器分析允许只读用户填表，到提交才被接口拒绝 | 按项目 experiment 权限、Public 身份及演示模式限制上传、分析和保存；已保存结果仍可查看，权限读取失败可重试 |
| P1 | 脚本归档前端没有与管理员专用接口对齐 | 文件选择、路径输入和提交统一限制为管理员且处于应用模式；继续允许浏览已有脚本 |
| P1 | 结果解读可重复提交，且只读用户也看到可执行按钮 | 权限、数据状态和请求进行状态共同控制解读按钮；项目切换时重置解释与临时状态 |
| P1 | 候选跳转结果页后，实验表被筛选，但仪器分析仍显示全项目内容 | 两处实验明细使用同一 candidate 筛选；未关联记录不混入该候选；保留分页、清除筛选，并明确项目汇总仍为全量 |
| P2 | Public 设置和账号页出现个人密码、模型配置或服务身份信息 | Public 提供 Private 访问入口和可用设置；账号页不再请求访客的服务账号详情 |
| P2 | 未选项目时点击设置“重新验证”，仍请求空项目的模型配置 | 仅在已选项目且有管理权限时读取和重试模型配置；访客不请求模型或集群设置 |
| P2 | 设置的全局“保存/取消”让人误以为能撤销即时主题修改 | 外观明确即时生效；关闭使用“完成”；模型保存和测试留在模型表单内 |
| P2 | 两块相同导览、不可用的导览按钮重复出现 | 合并指南与交互导览；无示例项目时不提供无效启动动作 |
| P2 | 项目页大幅重复研究团队角色和靶标准备内容 | 精简为工作区说明和项目列表；角色解释留在研究团队；靶标准备按需展开 |
| P2 | 仅打开项目页就自动同步示例研究 | 改为明确的“导入 / 更新示例研究”操作；保留已有项目和研究包合并规则 |
| P2 | Public 新建项目是无反馈的禁用按钮 | 提供“在 Private 新建项目”的有效入口；明确注册或登录后的用途 |
| P2 | 工作台菜单不能体现当前所在模块；Workflow 缺少主标题 | 显示当前工作台名称，补充 Workflow 页面标题及职责说明；只读空状态不再要求用户创建草稿 |
| P2 | 结果页缺少通往持续学习的直接入口 | 有实验结果时提供“用实验数据规划下一轮”，同时保留项目决策入口 |
| P2 | 失效路由呈现空白；页面渲染失败可能影响随后导航 | 增加页面不存在和返回项目入口；错误边界随路径及项目重置 |
| P2 | 文献证据包原文表格没有使用统一表格外观 | 复用 DataGrid 表格基础组件，保留原文表头、合并单元格、脚注和原始定位 |
| P3 | 窄屏 Public 提示占用过多纵向空间 | 缩短窄屏提示并收拢账号入口；保留桌面版说明 |

## 页面优化阶段验收

- Public 和 Private 分别检查 22 个页面/子视图：11 个主模块、5 个研究资料子视图、Bot 任务与交接、实验分析、BLI 工具、账号和失效路由。两组检查均未出现新的 API 失败或页面脚本异常。
- 实际运行匿名蛋白计算：20 aa 测试序列返回平均分子量 2395.713 g/mol；点击浓度换算后传入完整精度 2395.7134，保留单位与适用条件。
- 实际切换浅色/深色并关闭设置，主题即时生效；无项目时重新验证只请求服务健康接口，没有空项目请求。
- 以 Private 现有候选实际打开实验结果，确认 candidate 参数传递；未明确关联该候选的仪器读数被排除，清除筛选后可查看项目原始记录。没有按名字猜测或新增候选—实验关联。
- 390 px 窄屏与桌面检查：没有整页横向溢出，移动导航可横向滚动。窄屏进一步压缩了 Public 提示。
- 新增/扩展回归覆盖：项目切换、失效链接、服务失败与重试、访客账号页、设置请求边界、仪器权限、候选仪器明细筛选与分页。既有候选、Workflow、学习、Bot 和文献测试纳入全量前端测试。
- 实际工作区全量前端测试（184 个文件、1,186 项测试）、TypeScript/生产构建、bundle gate、ESLint 及差异空白检查通过。ESLint 保留 4 个既有 TanStack Table 兼容性提示，无错误。

本轮主要验证页面行为和接口衔接，没有重跑付费模型任务或集群计算，也没有改写实验原始数据。科学结论仍须根据每条证据的来源、关联关系和审核状态判断；页面可浏览不代表实验已经完成。

## 后续建议

1. 给每个项目维护一份明确的“当前问题—已有证据—待决策—下一步”摘要，链接现有实体，避免再建立重复的报告正文。
2. 将未绑定的实验样品列为人工核对任务：对照样品标识、构建体与候选版本后建立关联，再用于学习模型和候选比较。
3. 将本轮路由矩阵和匿名/授权两种会话纳入持续浏览器验收，重点保持证据筛选、跨页上下文、分页和只读边界一致。

提交方式：公共软件先提交到 Public 功能分支，再按不可变提交 SHA 同步到 Private 功能分支。Private 数据保持在 private/ 下。本次不创建发布版本或执行远程部署。


## 六维复审与新增修复

本节覆盖上述页面改动以及同批待提交的匿名工作区、账号入口、文献证据包与 Bot 文献任务合同。验收区分代码检查、隔离数据库集成测试和真实浏览器运行，不把页面能打开等同于所有计算或研究结论均已验证。

| 编号 | 优先级 | 复审发现 | 修复与验收依据 |
| --- | --- | --- | --- |
| A01 | P2 | `/public?view=tools` 跳转丢失工具和项目参数 | 保留查询参数，只消费兼容路由的 view；单测及浏览器确认工具与项目定位均保留 |
| A02 | P2 | Private 注册链接直接堆叠样式，可能被全局链接颜色覆盖 | 统一使用 Button 的链接渲染方式；浅色、深色实测文字对比度分别约 9.45:1、10.98:1 |
| A03 | P1 | 模型分析存在时会覆盖人工整理的文献论点显示 | 合并展示已整理论点与模型草稿；前端回归检查两者及原文链接同时存在 |
| A04 | P1 | 以原文表格为锚点的证据只显示空占位 | 锚点解析加入表格标题、单元格及脚注；保留表头与合并单元格，加入渲染回归 |
| A05 | P1 | 数字证据按子串匹配，21.2 可能误匹配 121.2、-21.2 或 21.2e3；数值 0 被当成空值 | 使用完整数值 token 校验，明确接受零值；负数、科学计数法和小数相邻场景均有回归 |
| A06 | P1 | 模型畸形结构可能触发类型异常或修改调用方输入 | 校验根对象、论点关系、锚点列表、数据值、图注及 gaps；拒绝布尔值与非有限数值；深复制输入并测试不可变性 |
| A07 | P2 | JATS 补充材料直接挂在根节点的链接未被提取 | 提取 supplementary-material 自身链接；保持未读取状态，不将链接存在视为补充材料已审阅 |
| A08 | P1 | 文献任务可能仅凭摘要或不完整分页就报告完成；异常分页元数据处理不稳健 | 新文献任务合同升级为 v2，要求论点、图、表、数据和补充材料覆盖；验证页界限、行数与 gaps，重叠页不重复计数；超大 total 不分配等长集合 |
| A09 | P2 | 新文献读取要求会使历史合同的窄范围测试失真 | 显式保留已存 v1 合同的验收条件；v2 完整性由独立测试覆盖，不降低新任务要求 |
| A10 | P2 | 新报告未进入文档索引，工具清单数量也滞后 | 补齐报告元信息与索引；按实际注册清单更新为 59 个工具（41 读、12 草稿写、6 入队），22 项能力 |
| A11 | P1 | 运行恢复后 Private 调度进程缺少队列标识，健康检查持续 503 | 修复本地调度环境的 scheduler 队列标识，重新加载服务；两套环境所有就绪检查通过，Private 22 个页面复测无新 API 错误 |

A11 属于本地运行配置修复，配置及凭据保存在仓库外；不通过放宽健康检查掩盖故障。文献中的模型解读始终保留“草稿待审核”语义，精确原文匹配也不代表科学因果关系已经成立。
