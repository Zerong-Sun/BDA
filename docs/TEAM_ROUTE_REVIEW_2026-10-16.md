# 团队协作与路线整理：六维验证和修复清单

核验日期：2026-10-16（Asia/Shanghai）。范围：项目群聊、Bot 委派与复核、用户选择后的恢复、路线展示和项目条目整理。科学结果的正确性与软件执行成功分别记录。

## 修复清单

| 问题 | 修复 | 验证依据 |
| --- | --- | --- |
| 群聊默认接收者随关键词变化，Bot 名称和旧称不一致 | 默认项目负责人；6 个角色使用清晰的中英文职责名，保留 ID、旧称和多词英文提及 | 聊天、提及和浏览器回归 |
| 聊天答应执行后没有持久调度入口 | 原始用户消息创建唯一团队任务；负责人分工、等待子任务、独立复核并汇报 | 团队生命周期、任务重复调用回归 |
| 启动团队任务被误标为只读操作，历史任务标记缺少归属校验 | 纳入显式授权写工具；校验项目、发起人、会话、目标及根任务身份；创建时审计 | 只读工具集合、跨项目标记与审计幂等回归 |
| “添加／补充文献”未被识别为明确行动 | 补齐中文意图词，保留否定与建议问句的拒绝规则 | 正向、否定、询问方式的授权测试 |
| 负责人可能重复要求已授予的权限 | 章程要求先核对原始请求，在既有授权内继续；只有缺少授权或输入时提问 | 能力限制和原始请求不扩大测试；真实模型复核 |
| 选中的最新进度简报未进入 Bot 上下文，负责人复述过期交接 | 非首选简报进入可检索、可引用的项目记录；列出近期简报及不可用的选中 ID，保留正式综述优先级 | 真实模型发现并复测；选择记录、项目隔离、能力限制和敏感字段回归 |
| 二次审阅丢失继续任务的原始目标和进度记录，硬编码“三条路线／香气／评分”让汇报偏题 | 审阅和修复保留当前请求、此前用户目标及有界项目记录；选中记录优先；方案数量、场景、成本和评分服从实际请求 | 负责人和研究员继续任务、审阅修复链路、项目记录排序／截断／隔离回归 |
| “不能推断不存在市场先例”及“没有专利库检索轨迹”被当作新颖性断言，触发多余重写 | 按短句识别明确否定的推断与缺少检索记录；同一回答中的独立无依据断言仍拦截；仅在用户要求时评分 | 中文否定、缺少检索记录、混合断言和跨句边界回归；保存的真实模型回复复核 |
| 选择答案后任务未继续，取消任务可能被恢复 | 决策接入持久等待；回答或撤回通过 outbox 恢复，取消状态不复活 | 回答、撤回、重载与取消回归 |
| 群聊缺少成员公开讨论，翻页可能遗漏仍在执行的工作 | 读取实际 assistant 发言；分页和轮询持续更新；隐藏推理、系统提示及原始工具输出 | 分页、跨项目隔离和隐私回归 |
| 审阅员只能看到工具调用，缺少待审阅的最终论断 | 单独提供有长度上限和截断标记的最终交付，仍与证据分开 | 有界交付和工具证据回归 |
| 数字、字母、长标题混用，设计、验证、校准和历史运行混杂 | 展示字段采用短名、分类、方法、说明、目标、证据、下一步、版本角色与旧名；选择器分组 | 数据整理执行指纹、页面和组件检查 |
| 改名丢失旧名，编辑图后分类丢失或标题不同步 | 自动保留旧别名；展示更新使用独立版本接口；图编辑保留展示字段并拒绝绕过改名接口 | 幂等、版本冲突、运行中记录和图编辑回归 |
| 异常分类或旧 JSON 让条目消失／修复失败 | 分类使用自有属性校验；未知分类进入未分类组；旧展示数据可修复 | `toString`、`__proto__`、空值及错误类型回归 |
| 展示折叠区域未使用统一 UI 组件；退出登录可能恢复旧项目 | 使用注册 Accordion；会话代际变化后禁止旧视图回填项目 | UI 规范检查、组件和登录退出浏览器回归 |

## 六个方面

| 方面 | 结论与边界 |
| --- | --- |
| 需求完整性 | 群聊负责人、单独提及成员、公开讨论、分工、进度、独立复核和用户决策均有入口；项目与路线整理包含方法文档及工作流展示。 |
| 逻辑正确性 | 原始用户请求是授权依据；审阅员不修写研究记录；任务状态与科学结论分开；重复启动不重复生成根任务。 |
| 边界情况 | 覆盖无权限、跨项目、否定请求、缺失／过期 If-Match、重复调用、取消恢复、旧称、坏 JSON、分页、登录切换和网络失败。 |
| 代码质量 | 跨领域更新走领域服务；没有新增数据库表或迁移；API 与生成客户端同步；静态检查和前端构建通过。 |
| 测试覆盖 | 单元、HTTP、数据库、组件及浏览器分层验证；新用例检查授权、不丢执行数据和实际可见行为。 |
| 实际运行 | 真实配置模型完成委派、研究员达到轮次上限后的恢复、外部文献检索、方案和审阅；真实数据库读取页面显示改名、解释与讨论。 |

## 运行边界

真实模型与文献工作使用指定任务的同步驱动，保留实际模型响应、领域服务操作和数据库记录；这不是“常驻 Celery 集群已部署新版”的证明。页面检查使用当前工作树的本地预览，未替换其他工作树的常驻服务。计算服务未启动，新计算和湿实验没有作为本次软件验收的一部分提交。

项目整理先备份、预检，再事务更新和回读。执行节点、参数、状态、来源与任务数量保持不变；旧说明和别名保留。文献来源分为相关、背景及离题，假设保持待验证，自动审阅不代替人工科学审核。私有数据、模型响应、备份和截图不随软件提交。
