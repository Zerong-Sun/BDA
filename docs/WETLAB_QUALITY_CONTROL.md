# 仪器分析与拟合质控

状态：2.6 开发分支的仪器质控软件能力；真实实验验收待完成。

最后核验：2026-10-11。

权威范围：仪器分析诊断、拟合质控审阅、候选指标投影与学习来源检查的当前契约。

数据来源：版本化源代码、合成曲线与隔离 HTTP/数据库测试；方法说明引用 SciPy 官方文档。

替代关系：补充 LEARNING_V26.md 和实验台说明，不替代真实 assay 验证协议或既有实验原始记录。

软件契约：`instrument-qc-v1`。这些检查判断数据与拟合的解释边界，不证明结合、酶活、纯度、测定有效性或实验成功。

## 使用路径

工作台 → 实验台 → 仪器分析。上传 BLI CSV、AKTA ZIP 或酶活 XLSX 后，原始制品保持不可变，分析产生新结果。结果仍默认 `pass_status=unknown`；拟合值不等价于 QC 接受或 assay pass。

1. 检查原始曲线、相界/时间窗、对照、单位、样品身份和列出的诊断。
2. 保存结果的 `instrument_qc_review.status` 初始为 `pending`，此时不写入候选实测指标。
3. 写明审阅依据后接受或拒绝。接受时要求有限数值与仍可用的来源；数值不可用时可以记录拒绝，不能接受为定量标签。
4. 接受才更新候选实测指标，预测指标继续独立保留。以后拒绝只删除指向该结果的派生候选指标，原始结果、拟合值和审阅历史均保留。接受仍不自动设为 `pass`。
5. 页面中的“读取已保存结果”可继续历史审阅，分批读取并支持刷新。没有新版 QC 的历史分析显示未审阅，须重新分析，不能把缺失检查当作通过。

审阅端点 `POST /api/v2/projects/{project_id}/wetlab/results/{result_id}/review` 接收 `{accept, rationale}`，要求实验权限与 `If-Match: W/"<version>"`；缺少版本 428、过期 412、跨项目结果 404、不可接受的空值 422。每次审阅在 experiments 服务保留操作者、时间、理由、QC 版本、历史，并写 audit。候选指标更新对候选加锁，避免不同结果并发审阅重复插入。

## 实际诊断

| 方法 | 返回的诊断 | 解释边界 |
|---|---|---|
| BLI | 有限点/缺失点数、严格递增时间、每相至少五点、有效浓度数、相界来源；联合拟合收敛状态、残差 RMSE、活动边界、列缩放 Jacobian 的数值秩/条件数；数值优化警告 | 五点是现有动力学拟合的最低输入条件，不是 assay 充分性标准；满秩只说明局部数值可辨识性，不证明生物学参数可辨识；没有伪造 KD 置信区间 |
| BLI 方法假设 | 推断相界待核实、终点等温线未证明达到平衡、1:1 模型的参比/浓度/传质/再结合前提 | 不从单一残差指标推断传质限制或再结合已经发生。三参数混合终点模型只有三浓度时提示残差自由度不足 |
| 酶活 | 全窗口 OLS 残差 RMSE、自由度、斜率标准误与条件 95% t 区间、Durbin–Watson 描述值、缺失/常数/重复时间诊断 | 两点不能估计残差方差；区间假设线性均值、独立正态且等方差残差；时间点不等于生物重复；不对 R² 或 Durbin–Watson 加任意“通过”阈值 |
| 酶活数据角色 | 原文件未标注背景时明确提示；最大孔斜率摘要、样品/对照及候选—孔位映射待审 | 全时程斜率不是自动确认的初始反应速率；常数响应不能区分无活性、检测限或仪器失败 |
| AKTA | 有限且递增体积轴、缺失点、边界截断峰、重叠积分窗、通道/单位说明 | 非 UV 通道保留图与峰表但不写蛋白 UV 峰面积数值；未知单位不猜测 mAU；峰面积不证明身份、纯度或回收量 |

保留既有分析方法：BLI 五法和信号过滤，AKTA Savitzky–Golay 平滑、5% 分位基线与积分，酶活背景算法与全窗口斜率。新版明确暴露其限制，并修正 AKTA 的 `CurveDataType` 可位于 XML 属性或子元素两种表示。非有限拟合输出变为不可用值，不变成零，也不生成 JSON NaN。读取仪器制品会核验长度与 SHA-256。

BLI 的 `least_squares` 在 robust loss 下返回经过修改的 Jacobian，所以本版只给数值诊断，未套用独立高斯残差的普通协方差公式来宣称参数区间。[SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。酶活区间使用固定 OLS 标准误和 n−2 自由度的 t 分位数，条件与 [SciPy 线性回归文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.linregress.html)一致。

## 与项目学习衔接

学习单条录入和 CSV 导入共用校验。若原始制品已有匹配候选（或未指定候选）的仪器分析，最新分析没有接受审阅时不能再标成 `qc_accepted=true`；返回 422 并提示先审阅仪器分析。失败、缺失和 `qc_accepted=false` 记录仍可保存。

学习结果保留仪器结果 ID 与版本。已经接受的来源后续改为拒绝或再次审阅时，旧学习标签在冻结时排除；已经训练的模型在提升、决策等来源检查中失效，须审阅、重新记录并冻结新快照。不会修改历史数据集和模型。

系统能核对同一制品与结果关联，不能自动识别用户重新上传文件或手工重写数值的语义等价性；原始记录治理、样品映射及诚实录入仍是实验责任人的工作。

## 尚未实施

本版没有自动选择酶初速时间窗，没有全局生物重复随机效应、稳健参数 bootstrap、质量传递模型、自动峰解卷积或 lmfit/Bayesian 拟合。新增方案须固定 assay 与对照数据验证，不能仅因拟合更复杂就替换当前模型。真实实验效益、仪器重现性和生产并发验收仍须另行完成。
