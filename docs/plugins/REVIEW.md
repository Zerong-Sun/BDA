# 全部 BDA 插件文档审计与审阅记录

日期：2026-09-15。结论：旧说明不完整；本轮已完成所有当前注册键的模式、参数及结果说明，并把不能确认或不能生效的部分明确标出。本次文档发布不表示这些运行缺口已经修复。

## 覆盖范围

- 19 个模型插件键，含 3 个 authoring 草稿；共 23 条模型版本记录。
- 4 个方法插件，全部为 demo-1.0 空 schema 注册记录。
- 共 23 份逐插件手册，由 20 份基础机器可读 profile 生成，草稿独立列版本和默认值。
- 覆盖历史 library 的 678 条参数记录、当前 BDA 字段及选定上游扩展；含同层 allOf/if/then/else 条件属性与大小写/短名别名。
- 去重按基础 profile 统计：886 项参数解释、98 种模式。草稿共用基础语义，未重复计入这两个数。
- 输入端口、各版本默认、CLI/配置映射、运行资源、派生文件/指标、单位、限制和来源均已列入。完整度是已知接口和明确模式的覆盖，不能解释为 Rosetta 任意 XML 或所有上游未来选项的无限全集。

## 旧说明的问题

旧目录只有 16 份基础模型集群 runbook，没有覆盖 authoring 草稿和方法 demo。runbook 主要解释 LSF 提交，缺少完整的功能模式与参数语义。原 library 中 RFdiffusion 116 项、BindCraft 289 项、Chai-1 18 项、Mask RGN 49 项、Rosetta 36 项和 AF3 1 项没有 help。Rosetta 清单实际 47 项，旧 parameter_count 仍写 36。本轮保留旧快照作为审计依据，统一手册按实际字段统计，不依赖旧 count。

新的手册不能只复述这些历史说明：审阅中通过官方固定 commit 源码发现了表单映射、输出尺度和帮助文字错误，并在本次文档中纠正。

| Boltz/草稿 | 表单 affinity 开关对应 --affinity，但固定上游使用 YAML properties.affinity；model/采样字段有映射差异 | 修正 YAML/CLI 适配，验证所用模型与真实输出；明确亲和力适用对象 |
| Chai-1 | 当前禁用；限制输入是 CSV，部分字段该版本不使用；默认 scores.npz 不自动保存 PAE 张量 | 验证约束契约、置信度尺度、实际输出文件 |
| BindCraft | 命令只传 settings/filters/advanced JSON，多个 UI 标量未写回；旧类型声明存在冲突 | 校验解析后 JSON 与请求一致；保留各模型原始值并检查 None 处理 |
| DiffAb | 禁用；命令与上游设计入口/模式参数不一致 | 补入口与字段映射，按设计模式验证固定区域和输出 |
| Mask RGN | 禁用；本地源码目录缺失，只有历史声明，不能据名称推断论文方法 | 找到实际源码/版本和安装，补输入端口、命令与有效样例 |
| Superfold / ProteinHunter | 包装器、官方代码与旧 runbook 的功能声明不完全一致 | 按固定版本 CLI 和 QM 变体源码复核，不能继承 Boltz 的所有功能 |
| Rosetta | 新版运行未验证；旧 2026.06 字段与命令不匹配；站点 root/bin 与旧 source/bin 布局需核实 | 核实安装和精确参数生效；原始 WT/MUT 分数需另行聚合，不能宣称已有 ΔΔG |
| APBS | 网格/介质/盐等配置自动生成，未单独暴露；输入仅选首个结构 | 保存实际 .in 与物理条件，补归档端口与结构/参数完整性检查 |
| Foldseek | 数据库前缀选择不稳；输出列含义随算法变化；旧 IP gate 解释过度 | 验证数据库完整性、算法与列定义，不用单个结构分数代替知识产权结论 |
| US-align | UI 把残基对应策略误写为归一化；多链/参考叠合矩阵未完整暴露 | 改清字段说明，按单体/复合体区分契约与输出 |
| 4 个方法 demo | 仅注册类型，无输入/参数/输出 schema；未找到按 key 执行的算法实现 | 在公式、模型/版本、单位、缺失处理及样例输出建立前，不参与候选排序 |

本次快照有 4 条登记 runtime_validation_status=proven 的记录（APBS、Foldseek、RFdiffusion3、US-align），但调用平台 runtime_validation_is_current 均为 false：没有与当前声明匹配的指纹。因此“当前有效运行证明”计数为 0，历史成功观察仍保留。这不是证明软件不能运行，而是当前证据不能证明这份声明已经验证。

## 独立审阅与已修正文档问题

1. RFdiffusion/MPNN 组审阅预测组：删去 Superfold 会产 ipTM 的错误暗示；PH/Superfold 的真实 CLI 不再泛称“非同名官方参数”。RFD1 B-factor 已按固定/扩散掩码解释；MPNN scores 输出按实际 NPZ 解释。
2. 预测组审阅规范、生成器、BindCraft/DiffAb：补上条件 schema 字段覆盖；拒绝非法模式状态、重复模式、空映射和错误文档 schema 版本。DiffAb 必需 pdb_path 不再写默认 null，metadata 里的配置路径不再冒充已经复制的 YAML。
3. 设计组审阅 APBS、Foldseek、US-align、Rosetta：纠正 US-align 不接受显式 -a 0；补 APBS 逐键生成配置；Rosetta 分开原始 WT/MUT 与未自动汇总的 ΔΔG，距离注明 cutoff 内范围；Foldseek alntmscore 按固定源码的较短对齐跨度解释。
4. 根代理整合：将上游扩展参数与真实 BDA 别名分开；旧 Rosetta 参数只提供语义对照，不承诺新版自动接受；所有未接入模式保留限制。
